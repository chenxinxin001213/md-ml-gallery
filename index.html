读图主线：从电场到面积变化的证据链

这套网页不是单纯图片库，而是一条可汇报的机制证据链。阅读时建议先看每张图的“读图导航”，再回到图本身核对坐标轴、趋势、误差和异常点。

1. 现象Area 随 E_Field 出现阈值型响应，并在 Ec 附近发生最快变化。
2. 物理定义S_order 跨零给 Ec 提供独立的取向有序化定义。
3. 机制路径E_Field 先改变偶极取向，再牵引氢键、能量和结构重排，最终影响 Area。
4. 稳健性跨 seed、跨变体、跨模型和外推/不确定性分析共同限定结论可信范围。
每张图都配有完整解读：图片下方依次说明“这张图回答什么问题、如何看懂、机制原理、结论与注意事项”。单图已默认展开，批量诊断图可按需展开。

Fig.1: Area 响应曲线

Fig1_area_response_curve.png ▸
读图导航：Fig.1: Area 响应曲线
这张图回答什么问题电场增强后，水膜/界面结构的平均面积是否出现非线性响应？临界电场 Ec 是否能从响应曲线中读出？
如何看懂先看蓝色点和误差条判断每个电场下的均值与置信区间，再看平滑曲线的斜率变化。绿色竖线是 Ec，灰色水平线提示高场下的饱和平台。
机制原理外加电场对水偶极施加力矩 tau = p x E，使偶极从随机/平躺取向逐步转为沿场方向取向。取向有序化会改变分子投影、氢键网络和界面排布，因此 Area 随电场上升并在取向趋于饱和后进入平台。
读图结论 / 注意事项如果 Ec 附近同时出现快速上升、误差条不主导趋势、之后进入平台，就支持“存在电场诱导的结构转变”而不是简单线性漂移。

汇报用途证明 Ec 的存在
坐标轴：横轴=E_Field(0→1.0 V/Å)，纵轴=Mean_Area(nm²)。
元素：蓝点=各电场平均面积(±95%CI)。深红曲线=平滑。绿竖线=Ec=0.205 V/Å。灰横线=饱和值。
核心故事：电场力偶矩τ=p×E驱动水偶极取向，分子从"趴着"变"站着"→面积增大。Ec是取向有序化完成的临界电场。
analysis.py → task_area_response_curve证明 Ec 的存在

Fig.2: S_order 序参数 — Ec 的物理定义

FigS1_s_order_response.png ▸
读图导航：Fig.2: S_order 序参数 — Ec 的物理定义
这张图回答什么问题Ec 是否只是从 Area 曲线人为选出的阈值，还是能由独立物理序参数定义？
如何看懂重点看 S_order 随 E_Field 是否从负值跨过 0 并转为正值。S_order=0 表示取向从无序/横向偏好过渡到沿场方向有序的分界。
机制原理S_order = 0.5(3cos^2 theta - 1) 衡量偶极与电场方向的取向关系。theta 接近 90 度时 S_order 为负，theta 接近 0 度时 S_order 为正。
读图结论 / 注意事项S_order 的零点给 Ec 提供物理定义，使阈值解释从“曲线拐点”升级为“取向有序化转变点”。

汇报用途Ec 的物理定义——序参数跨零点
元素：S_order从负(无序)跨零变正(有序)。跨零点=Ec。S_order=0.5(3cos²θ-1)，θ从90°(无序)到0°(有序)。
核心故事：Ec不是人为阈值，是序参数的自然零点。
analysis.py → task_s_order_responseEc 的物理定义——序参数跨零点

Fig.3: Bootstrap Ec 分布

Fig3_area_bootstrap_threshold.png ▸
读图导航：Fig.3: Bootstrap Ec 分布
这张图回答什么问题Ec 的估计是否稳定，还是依赖某一次采样或拟合？
如何看懂看 Bootstrap 分布的集中程度、均值位置和 95% CI 宽度。分布越窄，说明阈值估计对重采样越不敏感。
机制原理Bootstrap 反复从数据中重采样并重新估计 Ec，相当于模拟“如果重新做很多次同类实验，阈值会落在哪里”。
读图结论 / 注意事项CI 很窄说明 Ec 不是偶然点；如果分布偏斜或多峰，则需要警惕多个转变区间或拟合不稳定。

汇报用途Ec 统计置信度
元素：1000次Bootstrap的Ec分布。均值0.2047，95%CI=[0.2043,0.2051]。
核心故事：CI宽度仅0.0008→Ec极其稳定。

Fig.5: SHAP Summary — 核心机制

Fig10_shap_summary_enhanced.png ▸
读图导航：Fig.5: SHAP Summary — 核心机制
这张图回答什么问题机器学习模型认为哪些结构特征真正驱动 Area 预测？E_Field 是直接因素还是间接因素？
如何看懂纵轴按特征重要性排序，横轴是 SHAP 值，表示该特征把预测推高或拉低的贡献。颜色通常表示特征值高低：红色高、蓝色低。
