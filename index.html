Fig.1: Area 响应曲线

Fig1_area_response_curve.png ▾
坐标轴：横轴 = E_Field (0→1.0 V/Å)，纵轴 = Mean_Area (nm²)。
元素：蓝色散点 = 各电场下的平均面积 (±95% CI 误差棒)。深红曲线 = Savitzky-Golay 平滑。绿色虚竖线 = Ec = 0.205 V/Å。绿色带 = Ec CI。灰色虚横线 = 饱和面积。
如何看懂：曲线的 S 形态说明面积从增长→饱和。斜率最大的点 ≈ Ec——电场驱动面积变化最剧烈处。CI 带较窄 → 数据可信。饱和值 ≈ 23 nm²。
物理机制：电场力偶矩 τ = p×E 驱动水偶极沿场方向取向。分子从"趴着"变"站着"→投影面积增大。Ec 是取向有序化完成的临界电场。低于 Ec 热运动主导(无序)，高于 Ec 电场主导(有序)。
analysis.py → task_area_response_curve证明 Ec 的存在并展示电场驱动面积变化全貌

Fig.2/S1: S_order 序参数响应

FigS1_s_order_response.png ▾
坐标轴：横轴 = E_Field，纵轴 = S_order (-0.5→+0.5)。
元素：蓝点 = 各电场 S_order 均值(±95%CI)。橙色样条曲线。绿色竖线 = Ec。灰色横线 = S_order=0(无序/有序分界)。
如何看懂：S_order 从负(无序)跨零变正(有序)。跨零点 = Ec 的物理定义——这不是人为阈值，而是序参数的自然零点。曲线形态展示从随机取向→有序排列的转变过程。
物理机制：S_order = 0.5(3cos²θ-1)，θ 为水偶极与场方向夹角。θ=90°→S_order=-0.5(完全无序)，θ=0°→S_order=1.0(完全有序)。S_order=0 对应 θ≈54.74°——"有序倾向与热运动刚好抵消"的临界角。Legendre 多项式 P₂(cosθ) 天然适合描述各向异性体系的取向序。
analysis.py → task_s_order_responseEc 的物理定义——序参数跨零点自然标记无序/有序转变

Fig.S1a: Area 一阶导数

Fig2_area_derivative.png ▾
坐标轴：横轴 = E_Field，纵轴 = dArea/dE(变化率)。
元素：橙色点 = 各电场点的数值梯度。橙色曲线 = 平滑导数。绿色竖线 = Ec。绿色带 = Ec CI。灰色横线 = 0。
如何看懂：导数在 Ec 附近达峰值 → 面积变化最快处 = Ec。峰值尖锐 = 相变急促。如果平坦 = 渐变过程。
物理机制：dArea/dE = 系统对电场的瞬时响应速率。Ec 处最大 → 取向有序化的完成是面积变化的瓶颈步骤。Ec 之后取向饱和、进一步加场的影响减弱(导数回落)。
analysis.py → task_area_derivative_curve辅助定位 Ec——导数峰值 = 相变最剧烈的电场区间

Fig.3: Bootstrap Ec 分布

Fig3_area_bootstrap_threshold.png ▾
坐标轴：横轴 = Ec 值(V/Å)，纵轴 = 频数/密度。
元素：蓝色柱 = 1000 次 Bootstrap 的 Ec 分布。橙色 KDE 曲线。绿色竖线 = 均值 0.2047。半透明带 = 95% CI [0.2043,0.2051]。
如何看懂：分布窄而高 = Ec 极其稳定。CI 宽度仅 0.0008 → Ec 估计到小数点后四位都可靠。CI 不跨 0 → Ec 统计显著。
物理机制：Bootstrap 模拟"重做实验 Ec 会变多少"。1000 次重采样几乎不散 → Ec 不是特定数据划分的偶然产物，而是系统固有的物理性质。每个 Bootstrap 迭代对 E_Field 组块重采样(保持组内结构)。
analysis.py → task_area_bootstrap_thresholdEc 的统计置信度——1000 次 Bootstrap 验证

Fig.5/10: SHAP Summary (核心)

Fig10_shap_summary_enhanced.png ▾
坐标轴：横轴 = SHAP 值(正=推高 Area, 负=压低 Area)。纵轴 = 特征按平均|SHAP|降序。
元素：每点 = 一个样本的 SHAP 值。红点 = 该特征取值高，蓝点 = 取值低。灰竖线 = SHAP=0。
如何看懂：最上面的特征最重要。红点集中右半=高特征值推高 Area。蓝点集中左半=低特征值压低 Area。如果红蓝混在一起无趋势=不重要。
核心发现：cos_theta_x(偶极取向)排第1，S_order 排第2，SHAP 值远超其余。E_Field 本身 SHAP≈0 → 电场不直接决定面积，而是通过改变取向/有序度间接作用。这个发现直接催生了你的中介分析。
机制：SHAP 基于 Shapley 值(合作博弈论)。每个特征的 SHAP = 该特征在所有可能特征子集下的平均边际贡献。Beeswarm 同时展示重要性(行序)、方向(横轴)、分布(点散布)、特征值(颜色)四个维度。
analysis.py → task_shap_summary_enhanced核心发现——电场通过结构中介变量间接驱动面积变化

Fig.7: PDP 部分依赖图

Fig7_area_pdp.png ▾
坐标轴：每子图横轴 = 特征真实值，纵轴 = 模型预测的 Area 边际效应。
元素：蓝色粗线 = PDP 均值(所有样本平均)。蓝色细线 = ICE 个体条件期望。红色虚线 = 均值线。
如何看懂：PDP 线平坦 = 无效应。有坡度 = 该特征独立影响预测。ICE 线分散 = 不同样本间效应不同(存在交互)。
注意：在 cos_theta_x 和 S_order 共线体系下，PDP 可能产生虚假外推(A model 没见过"S_order高但cos_theta_x低"的组合)。ALE(Fig.8)更可信。但 PDP 和 ALE 的共同结论增强了鲁棒性。
机制：PDP 通过"冻结"其他特征、只变目标特征并取平均来估计边际效应。是模型无关的可解释性方法——与 SHAP 互补的第二套独立证据。
analysis.py → task_area_pdp模型无关的可解释性——与 SHAP 互补的第二套证据

Fig.8: ALE 累积局部效应

Fig8_area_ale.png ▾
坐标轴：每子图横轴 = 特征真实值，纵轴 = ALE(局部效应累积)。
元素：蓝色粗线 = ALE 曲线。阴影 = 置信带。
如何看懂：ALE 斜率 = 该处边际效应。线平 = 无效应。线升 = 特征增大推高 Area。
为什么比 PDP 更可信：ALE 只在"模型实际见过"的数据区域内计算局部效应并累积，避免了 PDP 的外推偏差。在共线体系下 ALE 是 PDP 的稳健替代。
机制：ALE 将特征值域分为小区间，在每个区间计算模型预测的局部变化再累积。与 PDP 的一致结论增强了"cos_theta_x/S_order 对 Area 有正向边际效应"的可信度。
analysis.py → task_area_alePDP 的稳健替代——在共线体系下比 PDP 更可信

Fig.9: 特征消融

Fig9_area_feature_ablation.png ▾
坐标轴：横轴 = ΔR²(移除特征后 R² 下降量)，纵轴 = 特征(按 ΔR² 降序)。
元素：蓝色横条 = R² 下降。条越长 = 移除该特征对模型损伤越大 = 该特征越不可替代。
如何看懂：与 SHAP 对比——SHAP 说"谁重要"，消融说"没有谁不行"。两者应高度一致。不一致 → 某特征 SHAP 高但消融低 = 有别的特征能替代它。
机制：每次移除一个特征，重训模型，测量 R² 变化。模拟"缺少某个观测量的情况下 ML 还能不能预测"的物理实验。
analysis.py → task_area_feature_ablation特征必要性验证——不是"重要"而是"不可替代"
