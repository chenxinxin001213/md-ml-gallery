📊 核心物理发现 + 机制

Fig.1: Area 响应曲线

Fig1_area_response_curve.png ▸
坐标轴：横轴=E_Field(0→1.0 V/Å)，纵轴=Mean_Area(nm²)。
元素：蓝色散点=各电场平均面积(±95%CI)。深红曲线=Savitzky-Golay平滑。绿色虚竖线=Ec=0.205 V/Å。绿带=Ec CI。灰色虚横线=饱和面积。
核心故事：电场力偶矩 τ=p×E 驱动水偶极沿场方向取向。分子从"趴着"变"站着"→投影面积增大。Ec 是取向有序化完成的临界电场。
analysis.py → task_area_response_curve证明 Ec 的存在

Fig.2: S_order 序参数 — Ec 的物理定义

FigS1_s_order_response.png ▸
坐标轴：横轴=E_Field，纵轴=S_order(-0.5→+0.5)。
核心故事：S_order 从负(无序)跨零变正(有序)。跨零点=Ec的物理定义——不是人为阈值，是序参数的自然零点。S_order=0.5(3cos²θ-1)，θ从90°(无序)转到0°(有序)。
analysis.py → task_s_order_responseEc 的物理定义——序参数跨零点

Fig.3: Bootstrap Ec 分布

Fig3_area_bootstrap_threshold.png ▸
元素：1000次Bootstrap的Ec分布。均值=0.2047，95%CI=[0.2043,0.2051]。
核心故事：CI宽度仅0.0008→Ec估计极其稳定，不是特定数据划分的偶然产物。
analysis.py → task_area_bootstrap_thresholdEc 统计置信度——1000次Bootstrap验证

Fig.S1a: Area 一阶导数

Fig2_area_derivative.png ▸
元素：dArea/dE随电场变化。导数在Ec附近达峰值→面积变化最快处=Ec。
核心故事：辅助验证Ec位置。峰值尖锐=相变急促。Ec之后取向饱和、导数回落。
analysis.py → task_area_derivative_curve辅助定位Ec——导数峰值

Fig.5: SHAP Summary — 核心机制

Fig10_shap_summary_enhanced.png ▸
坐标轴：横轴=SHAP值(正=推高Area,负=压低)。纵轴=特征按|SHAP|降序。
核心故事：cos_theta_x(偶极取向)排第1，S_order排第2，SHAP值远超其余。E_Field本身SHAP≈0→电场不直接决定面积，而是通过改变取向/有序度间接作用。这个发现直接催生了中介分析。
analysis.py → task_shap_summary_enhanced核心发现——电场间接驱动，通过取向有序度

Fig.11: 物理机制总览

Fig11_area_mechanism_diagram.png ▸
元素：因果链 E_Field→τ=p×E→取向有序化→氢键重组→面积↑。
核心故事：论文所有发现的视觉汇总。自下而上的多尺度因果链。
analysis.py → task_area_mechanism_diagram综合机制图——论文视觉总结

Fig.4: 特征相关性热图

Fig4_area_correlation_heatmap.png ▸
元素：14个特征Spearman相关矩阵(蓝正红负)。
核心故事：cos_theta_x和S_order强共线(r>0.95)——同一物理过程的两面，天然共线。确认共线结构需要被正视。
analysis.py → task_area_correlation_heatmap特征工程验证

核心故事：与SHAP互补——SHAP说谁重要，消融说没有谁不行。

pca_full_analysis.png ▸
四面板：PC1 vs PC2散点+loading+解释方差+loading箭头。
核心故事：PC1解释70.2%方差，cos_theta_x/S_order loading最大——与SHAP完全一致。PCA完全不依赖物理标注，构成了第三套独立验证。
analysis.py → task_pca_full_analysis第三套独立可解释性——PCA线性代数路线

UMAP 状态演化轨迹

umap_trajectory.png ▸
元素：二维非线性投影。灰线=电场升序轨迹。绿圆=起点，红方=终点。
核心故事：第四套独立验证——UMAP(非线性流形学习)与PCA(线性)的一致结论。Ec附近轨迹转折=相变信号。
analysis.py → task_umap_trajectory第四套独立可解释性——UMAP流形学习
